# PCB-PCB-Board-Intelligent-Inspection-System-
是一套面向 PCB 外观检测的装置，由 FPGA 采集节点和 PC 检测上位机两部分组成，检测范围限于可见表面，不涉及内部电气与深层缺陷。(It is a device specifically designed for PCB appearance inspection. It consists of an FPGA acquisition node and a PC detection host. The inspection scope is limited to the visible surface and does not cover internal electrical or deep defects.)
