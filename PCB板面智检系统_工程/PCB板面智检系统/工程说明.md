# PCB 板面智检系统

FPGA 采集、显示、存储与自动对焦工程，以及三通道 PC 检测程序。
基线：FPGA V26.7，PC 1.6.0。清理只调整交付目录与构建入口；活动 RTL、时序/引脚约束、PC 算法源码和发布二进制保持原样。

## 直接使用

- FPGA：烧录 `FPGA工程/bitstreams/PCB_Camera.bit`。
- PC：完整解压后运行 `PC上位机/启动三通道检测.bat`。EXE 和 `_internal` 必须在一起；运行时自动生成 data。
- 复位/上电时不按编号键选板 1，按住左键 K4 选板 2，按住右键 K5 选板 3；不要两键同时按。编号显示于板载数码管。
- 板 1/2/3 地址为 192.168.137.2/.3/.4，图像目的端口为 16001/16002/16003；PC 接收地址设为 192.168.137.1，控制端口 6002。路由器组网时避免 DHCP 与这些固定地址冲突。
- 每路默认 1080p / 2 fps。三路像素与 SCAM 头预算约 203.6 Mbit/s，另有 UDP/IP 和无线开销；建议 5 GHz。三路回放已验证，真实三板无线吞吐仍需现场验收。
- 本地手动升降为 750～2250 µs、20 µs 步长，OK 应用且留在菜单；舵机外部供电并共地。PC 远程界面范围较宽，当前机构应自行设置同样的安全范围。

## 修改与构建

- FPGA 使用 Anlogic TD 6.2。`project/PCB_Camera.al` 为相对路径源码工程；内部目标名保留以匹配构建脚本。
- 配置 `ANLOGIC_HOME` 为 TD 安装目录（默认 D:/TD_6_2/Anlogic），Python 3 运行 `构建工程.bat`。自动完成综合、布局布线、CDC 连接检查、时序复核和导出；任一步失败应停止使用新产物。生成的 work/review 不随本包交付。
- 修改 GUI/算法后，在独立 Python 环境运行 `PC上位机/构建上位机.bat`，结果在 dist。requirements 列出直接依赖；现成 EXE 自带运行时，无需安装 Python。
- 保留 DDR IP 的加密 RTL、参数文件、头文件与 PHY ROM；这些是工程依赖，不能删。两项布线后审计脚本是发布构建流程的一部分，不是仿真测试。

## 目录清理

本包不含仿真测试、实验数据/图片、报告、历史构建数据库、缓存与旧版本。随包仅保留工程、可运行产物、必要依赖和本说明。原始工作目录未改动。
`文件校验.json` 记录全部交付文件的 SHA256，可用于检查解压完整性。
